# Petition Review Flags

CS4535 Team 4 prototype for Indiana's Protection Order E-filing Service.

- **Petitioner preview:** neutral "Before you sign" notes (missing dates/places, single-incident stalking petitions, possible confidential info in public fields). Filing is never blocked.
- **Court staff queue:** petitions listed in the order received, with petitioner-reported safety flags and completeness flags. No scoring or ranking.

The petitioner side is four pages (why you are filing, what happened, safety questions, review and sign). Each page says what it is for and has "How to fill in this page" instructions beside the fields; the review page links back to each page to edit. Each incident can list photos or files; in this prototype only the file names are kept and nothing is uploaded. Light mode is the default, with a dark mode toggle in the header.

Open `index.html` in a browser, or view it on GitHub Pages once enabled.

Prototype only; not an official court site and not legal advice.
